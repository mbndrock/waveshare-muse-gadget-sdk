# Jollybot reaction previews

These GIFs show Meta's Jollybot avatar with the complementary reactions this
fork adds (dizzy, sleepy, waking, tickled, and in the car VTEC, coolant
HOT! and warm-up), rendered on a computer from
`esp32/avatar/muse_pixel.c`. The car ones come from the frame dumps of
`esp32/tests/muse_pixel_{vtec,coolant,warmup}_harness.c`.
